Website Hosting Options

Do not point the domain to Google unless the website is hosted on Google Sites. Google Workspace DNS for mail can coexist with a website hosted elsewhere.

When using Google Sites

  • Add the custom domain in Google Sites or Google Admin.
  • Add a CNAME record with host www and value ghs.googlehosted.com.
  • Forward viliganscommandcorp.com to https://www.viliganscommandcorp.com.

When using OpenAI Sites

Keep the Google TXT and MX records for email only. Website DNS should use the OpenAI Sites custom-domain records rather than ghs.googlehosted.com. The OpenAI TXT record is already present, but the custom domain still needs to be attached in OpenAI Sites.
